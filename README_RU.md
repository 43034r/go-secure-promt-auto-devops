# go-secure-promt

**Безопасный раннер AI-агента для GitLab CI/CD пайплайнов.**

Написан на Go. `secure-promt` встраивает LLM-агента непосредственно в CI-пайплайн. Агент получает высокоуровневую задачу — например, расследование падения деплоя или анализ логов Kubernetes — и самостоятельно выбирает и исполняет инструменты, необходимые для её решения.

**Шифрование промтов.** Перед запуском задачи оператор шифрует цель командой `secure-promt provision`. Полученный payload защищается алгоритмом AES-256-GCM с использованием ключа, хранящегося на хосте с правами root-only. При выполнении команды `secure-promt execute` расшифровка происходит в памяти — открытый текст промта никогда не попадает в описание CI-задачи, логи или переменные окружения.

**Внедрение секретов на этапе сборки.** API-ключи LLM (OpenAI, Google Gemini) компилируются непосредственно в бинарный файл через флаг `-ldflags` на этапе сборки. Они не существуют в виде файлов или переменных окружения на раннере, что снижает риск утечки учётных данных.

**Фаервол перехвата команд.** Через механизм DEBUG trap в `bash` перехватывается каждая shell-команда, выполняемая в процессе CI-задачи. Перед исполнением команда проверяется по строгому списку разрешённых операций — это блокирует атаки через инъекцию в скрипты, которые иначе могли бы перехватить shell-доступ агента.

**Динамический набор инструментов через MCP.** Агент обнаруживает доступные инструменты в runtime из каталога MCP-серверов (Model Context Protocol — JSON-RPC поверх SSE). Это открывает доступ к структурированным интеграциям: вызовы GitLab API, получение логов Kubernetes, операции Helm — без необходимости работать исключительно через shell-команды. В качестве LLM-бэкенда используется библиотека [langchaingo](https://github.com/tmc/langchaingo).
